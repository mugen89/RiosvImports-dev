# RIOSV Imports

Windows програма за отчетите към **НИСО** (Националната информационна система
за отпадъци): попълване, проверка, електронен подпис и готов XML за качване.
До нея — складът на площадката (приемане, третиране, образуване, предаване), от
който отчетната книга се съставя сама, и балансът по кодове и месеци.

Замисълът е услуга с абонамент. Подписът е причината, поради която си струва:
НИСО отхвърля неподписан файл още при импорта, а полагането на подпис върху
XML е точно техническата стъпка, която хората плащат да не правят сами.

> **Състояние:** работи за годишните отчети и отчетните книги. Тримесечните не
> минават (един потвърден дефект). Услугата зад абонамента още я няма.
> Подробно: [docs/СЪСТОЯНИЕ.md](docs/СЪСТОЯНИЕ.md).

## Пускане

```powershell
dotnet build
dotnet run --project src\RiosvImports.App
dotnet run --project src\RiosvImports.App -- --zoom 1.5     # както на лаптоп при 150 %
dotnet run --project src\RiosvImports.App -- --db проба.db  # друга база, не тази в профила
dotnet run --project tests\RiosvImports.Tests              # над 700 проверки
```

Нужен е .NET 9 SDK. Тестовете нямат външни зависимости: подписът се проверява
със самоподписан сертификат в паметта, а пробата с истинския износ от
„Деметра“ се пропуска сама, ако файлът го няма.

Програмата държи `.dll` файловете заключени — затваря се преди сглобяване.

## Издания и обновяване

Докато програмата се разработва, всичко е тук, в това публично хранилище:
изданията под [Releases](https://github.com/mugen89/RIOSVImports-Dev/releases), а
новините — в [news.json](news.json) в корена. Програмата пита GitHub без ключ.
За истинското издаване кодът може да мине в частно хранилище, а изданията — в
отделно публично (образецът е в `tools/releases-repo`).

- При пускане програмата пита за ново издание и за новини. Отговорът излиза в
  „Известия“ на началния екран; нищо не се сваля и не се слага без копче.
  Проверката се изключва от „Настройки → Обновяване“.
- Новина: редактирайте `news.json` направо в GitHub. Стига до всички при
  следващото им пускане.
- Издание: `.\tools\release.ps1 -Version 1.3.0 -Upload` — или етикет `v1.3.0`,
  който пуска работния поток `release`. Бележките на изданието са разделът
  от [CHANGELOG.md](CHANGELOG.md); хората ги виждат в програмата.
- Адресът на хранилището с изданията е един ред: `UpdateFeed.Repository`.

Подробно, стъпка по стъпка: [docs/КЪМ_GITHUB.md](docs/КЪМ_GITHUB.md).

## Какво прави

1. **Избираш вид отчет** — 42 вида в четири схеми: годишни, тримесечни,
   отчетни книги, общи типове.
2. **Попълваш** — в програмата, в Excel шаблон или от склада („Месец“ и
   „Склад“), откъдето отчетната книга се съставя сама.
3. **Проверяваш** (F5) — грешките излизат долу; двоен клик отваря мястото.
4. **Създаваш файла** — XML по схемата, подписан с твоя КЕП.

Работата стои в местна SQLite база в `%LOCALAPPDATA%\RIOSV Imports`. Нищо от
нея не се качва никъде.

## Устройството накратко

**Нито един отчет не е написан на ръка.** Листовете, колоните, падащите
менюта, проверките, упътванията и структурата на XML файла се извличат при
стартиране от официалните XSD схеми:

```
schemas/*.xsd ──► XsdReader ──► модел на 42-та вида отчет
                                   │
                     ┌─────────────┴─────────────┐
                     ▼                           ▼
              TemplateBuilder              SheetGrid
              (Excel шаблон)          (таблиците в програмата)
                     │                           │
                     └──────────► XML ◄──────────┘
                                   │
                            XsdValidator · XmlSigner (XAdES-BES)
```

Затова добавена от НИСО колона се появява сама.

| Проект | За какво |
|---|---|
| `src/RiosvImports.Core` | схеми, Excel, XML, подпис, проверка; складът и балансът като сметка |
| `src/RiosvImports.Data` | SQLite: отчети, редове, фирми, склад, настройки, новини |
| `src/RiosvImports.Account` | профил и право на ползване (подписано с ES256) |
| `src/RiosvImports.App` | Windows Forms; обновяването и новините са в `Updates/` |
| `tests/RiosvImports.Tests` | една програма, над 700 проверки, и преглед за лаптоп при 100/125/150 % |
| `tools/` | издание, изнасяне в чиста папка, ключ за правото на ползване, пробни данни |
